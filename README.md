# 🚌 Bus Booking Website

A modern and responsive **Bus Booking Website** built using **HTML5, CSS3, and JavaScript**. The project provides a clean and user-friendly interface for searching buses, viewing routes, and exploring a seamless booking experience.

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/abhimanyu-tiwari/Bus-Booking-Website.git
```

Navigate to the project folder

```bash
cd Bus-Booking-Website
```

Open **index.html** in your preferred web browser.
